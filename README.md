# portfolio-models

3D models for davisgentry's portfolio, served through jsDelivr.

| File | What it is |
| --- | --- |
| `chair3.glb` | pkl chair: baked PBR textures (base colour, ORM, normal), meshopt-compressed, 4.7 MB |
| `chair3-viewer.html` | Local test page using `<model-viewer>` |

Load a model by tagged URL, e.g. `https://cdn.jsdelivr.net/gh/daaaaavia/portfolio-models@v1/chair3.glb`.
The files are meshopt-compressed, so the viewer needs the meshopt decoder (see `chair3-viewer.html`).
